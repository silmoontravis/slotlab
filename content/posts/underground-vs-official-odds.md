這系列寫到最後一篇，該把所有數字放在同一張表上了。前面七篇我每篇都說「地下回收率比台彩高，但風險沒辦法用賠率補回來」，這篇就把這句話拆成算式：回收率怎麼算、台彩的 55% 怎麼來、地下的 81%～101% 怎麼來，然後把那些「算不進去」的東西一個一個拿出來看。

先講我的立場：我是拆系統的人，不是勸你去哪裡的人。這篇的結論是「地下的期望值算不出來」，不是「地下比較划算」也不是「台彩比較划算」。

:::tip
**TL;DR**
- 統一公式：回收率 = 賠率 × 中獎機率 + 退水比例。用這條公式，地下 539 二星以坊間常見賠率換算約 81%～101%，台彩今彩539 約 55%（我用 4,000 期實際資料算出 53.45%）。
- 回收率高不等於期望值高：真正的期望值要乘上「對方會付錢的機率」、扣掉「被降倍的那一注」、再扣掉「刑法第 266 條的法律成本」，這三個變數沒有人能可靠估計。
- 台彩 55% 的回收率是確定的、公開的、有國家保證支付的；地下的數字是條件式的。兩個不是同一種東西，不能直接比大小。
:::

## 統一公式：賠率怎麼換算成回收率

不管哪一種玩法，回收率（RTP）的算法都一樣：

**回收率 = 賠率 × 中獎機率 + 退水比例**

中獎機率用組合數算，公平倍數就是 1 ÷ 機率。賠率 ÷ 公平倍數也會得到同一個回收率。我在 [莊家優勢怎麼算](/rtp/house-edge-explained) 講老虎機時用的就是這條，只是那邊的「賠率」是賠付表、「機率」是符號出現率。

```python
from math import comb
def rtp(odds, p, rebate=0.0):
    return odds * p + rebate

p2_539 = comb(5, 2) / comb(39, 2)      # 10/741 ≈ 0.01349
p2_m6  = comb(6, 2) / comb(49, 2)      # 15/1176 ≈ 0.01276
print(rtp(70, p2_539), rtp(60, p2_m6)) # 0.9447, 0.7653
```

## 地下常見賠率換算表（坊間區間，不代表任何盤口）

下表的「坊間常見區間」是我在公開討論裡看到的範圍，各盤口差異很大、而且會因降倍臨時變動。我沒有、也不會實測任何盤口，請把它當成「理解算式的參數」。退水另外加，表格先不含退水。

| 玩法 | 中獎機率 | 公平倍數 | 坊間常見區間 | 換算回收率 |
|---|---|---|---|---|
| 539 二星 | 10/741 ≈ 1.349% | 74.1 | 約 60～75 倍 | 約 81%～101% |
| 539 三星 | 10/9,139 ≈ 0.109% | 913.9 | 約 700～900 倍 | 約 77%～98% |
| 539 四星 | 5/82,251 ≈ 0.0061% | 16,450 | 約 8,000～12,000 倍 | 約 49%～73% |
| 六合彩 二星 | 15/1,176 ≈ 1.276% | 78.4 | 約 55～65 倍 | 約 70%～83% |
| 六合彩 三星 | 20/18,424 ≈ 0.109% | 921.2 | 約 550～650 倍 | 約 60%～71% |
| 六合彩 特碼 | 1/49 ≈ 2.04% | 49 | 約 40～45 倍 | 約 82%～92% |
| 六合彩 單雙 | 25/49 或 24/49 | 1.96 或 2.04 | 約 1.9 倍 | 約 93%～97% |

幾個觀察：

- **星數越高，回收率越低**。四星的坊間賠率離公平倍數最遠，因為盤口要控制極端賠付（[組頭層級那篇](/lotto/underground-bookie-tiers) 講過限注的原因）。
- **二星是地下回收率最高的玩法**，區間上緣甚至接近 100%。這就是「地下賠率比較好」這句話的來源，它在二星上是數學事實。
- 加上退水之後，部分組合的回收率會超過 100%，這在 [退水與佔成那篇](/lotto/underground-rebate-and-share) 我算過，也解釋了為什麼那種組合通常伴隨較低的賠率或更嚴的限注。

:::david
我做這張表的時候，有一度很想把坊間區間拿掉，只留公平倍數，因為我真的沒辦法為任何一個區間負責。最後還是留下來，原因是：如果你看到任何人報一個賠率，拿它除以公平倍數就是回收率，這個動作比我的表重要一百倍。表會過時，公式不會。

## 台彩今彩539 的回收率怎麼算

台彩官方玩法頁的獎金結構，一注 50 元：

| 獎項 | 條件 | 獎金 | 機率 | 機率 × 獎金 |
|---|---|---|---|---|
| 頭獎 | 中 5 顆 | 8,000,000 | 1/575,757 | 13.89 元 |
| 貳獎 | 中 4 顆 | 20,000 | 170/575,757 | 5.91 元 |
| 參獎 | 中 3 顆 | 300 | 5,610/575,757 | 2.92 元 |
| 肆獎 | 中 2 顆 | 50 | 59,840/575,757 | 5.20 元 |
| 合計 | | | | 27.92 元 |

27.92 ÷ 50 = 55.8%。這是理論值。我再用資料檔（台彩官方 API，2014-01-01 到 2026-10-03 共 4,000 期）把每期的實際銷售額跟實際派出總獎金加總：53.45%。差的 2.4 個百分點主要是頭獎無人中的期數（那 800 萬不會派出去）。

大樂透跟威力彩因為頭獎是累積制，單期回收率會因為累積金額大幅變動，我在 [三種樂透期望值比較](/lotto/lottery-expected-value) 那篇另外算，這裡不混在一起。

## 把「算不進去的東西」放進期望值

現在是重點。回收率是在「賠率固定、對方一定付、沒有外部成本」的假設下算的。真實的期望值要再乘、再扣三個東西：

**1. 履約機率 q**：地下盤口付不出來的情況叫倒帳。真實期望回收 = 回收率 × q。q 是多少？沒有人知道，也沒有任何資料可以估。台彩的 q 是 1，由國家特許的發行機構保證。

**2. 降倍的逆選擇**：降倍只發生在你押的組合很多人押的時候，那通常也是你押最多的時候。假設你 80% 的注額在正常賠率（回收率 94.5%）、20% 在被降倍的熱門組合（賠率 50 倍，回收率 67.5%），加權回收率是 0.8 × 94.5% + 0.2 × 67.5% = 89.1%。降倍的比例越高，差距越大。

**3. 法律成本 L**：刑法第 266 條處罰賭博財物的行為，2022 年修法後明文把透過電信、網路等方式賭博納入，法定刑為罰金；第 268 條處罰意圖營利供給賭博場所或聚眾賭博，法定刑為有期徒刑等級。條文細節以全國法規資料庫為準。這個成本不是機率乘金額能算完的，它還包含紀錄與時間。

把三個放進去：

**真實期望值 = （加權回收率 × q）− L**

| 項目 | 地下 539 二星（假設賠 70 倍） | 台彩今彩539 |
|---|---|---|
| 帳面回收率 | 94.5% | 55.8%（實算 53.45%） |
| 降倍後加權回收率 | 依比例，例如 89.1% | 不適用（獎金固定） |
| 履約機率 q | 未知 | 1 |
| 法律成本 L | 刑法第 266 條，不可量化 | 0 |
| 真實期望值 | **算不出來** | 55.8% × 1 − 0 = 55.8% |

這就是我整系列的結論。不是「地下比較差」，而是**地下的期望值沒有任何一個變數是可靠的**：賠率會變、對方會不會付不知道、法律成本沒辦法量化。台彩的 55% 很低，但它是一個每項都確定的數字。

```python
rtp_normal, rtp_cut, cut_ratio = 0.945, 0.675, 0.20
weighted = (1 - cut_ratio) * rtp_normal + cut_ratio * rtp_cut   # 0.891
q = None   # 履約機率，沒有資料可估
L = None   # 法律成本，無法量化
# 真實期望值 = weighted * q - L  → 無法計算
```

:::david
我是寫程式的人，看到一個公式裡有兩個 None 就會想辦法填值。這題我試過：假設 q = 0.95、L = 0，結果 89.1% × 0.95 = 84.6%，還是比 55.8% 高。但我馬上意識到問題不在數字，在於那個 0.95 是我編的。我寫這整個系列的原則是「每個數字都要能回溯到來源」，q 跟 L 做不到，所以我選擇把它們留白，而不是給一個好看的答案。
:::

## 這系列的總結：拆完之後我學到什麼

寫了八篇，我把地下簽賭的術語從頭拆到尾，學到三件事：

**第一，所有花式名稱都收斂到組合數。**二三四星、連碰、全車、立柱、台號，每一種都能用 C(n,k) 或簡單的模擬算出機率，沒有例外。我用 4,000 期今彩539 資料回測了四種圈法，每碰中獎率全部落在 10/741 附近。

**第二，盤口的結構是為了活下來，不是為了公平。**退水是價格競爭、佔成是風險分攤、降倍跟限注是曝險控制。每一個機制都有合理的數學解釋，而且每一個都對會員不利。

**第三，回收率不是期望值。**地下的回收率確實比較高，但它是一個條件式的數字，條件不成立時就是零。台彩的回收率低，但沒有條件。

如果你是因為「想理解這些詞」來看這系列的，我希望這八篇有把規則講清楚。如果你是來找「哪裡划算」的，答案是：我算不出來，而且我不認為有人算得出來。想了解合法彩券的機率，看 [今彩539 玩法與獎金](/lotto/daily539-how-to-play)；想理解為什麼回收率再高長期還是會輸，看 [長期模擬](/rtp/long-term-simulation)；想認真看自己的賭博習慣，看 [負責任博彩](/guides/responsible-gambling)。

## 常見問題

**地下賠率怎麼換算成回收率？**
回收率 = 賠率 × 中獎機率 + 退水比例。539 二星中獎機率是 10/741，賠 70 倍、退水 0 的回收率就是 70 × 10/741 ≈ 94.5%。公平倍數是 1 ÷ 機率，賠率 ÷ 公平倍數也會得到同樣的結果。

**台彩今彩539 的回收率是多少？**
用官方獎金結構算，一注 50 元的期望回收約 27.9 元，回收率 55.8%。我用 2014 到 2026 年共 4,000 期的實際銷售額與總獎金算出來是 53.45%，頭獎無人中的期數會讓實際值略低於理論值。

**地下回收率比台彩高，是不是表示地下比較划算？**
數學上回收率確實比較高，但那是「對方一定付錢、賠率不會被降、沒有法律後果」三個前提下的數字。把履約機率、降倍、刑法第 266 條的風險放進期望值，結果就算不出來了，因為這三個變數沒有人能給你可靠的估計。

**為什麼降倍對期望值影響那麼大？**
因為降倍只發生在你押的組合被很多人押的時候，而那通常也是你最有把握、押最多的時候。被降倍的那組回收率可能從 94.5% 掉到 67.5%，而且是在你最想贏的那一注上發生。
