<p>累積獎池（Progressive Jackpot）是老虎機世界裡最讓人心跳加速的元素。那個不斷跳動的數字、動輒上千萬的獎金 — 光是看著就讓人興奮。但在工程師的眼裡，累積獎池是一個非常有趣的數學系統。今天我要來解析它是怎麼運作的，以及從數學的角度來看，什麼時候玩是最「合理」的。</p>

<div class="david-note">先說結論：累積獎池老虎機的 Base RTP 通常比一般老虎機低，因為有一部分 RTP 被「抽」去填獎池了。所以除非你是衝著那個大獎去的，否則一般老虎機的期望回報其實更好。</div>

<h2 id="how-it-works">累積獎池的運作機制</h2>
<p>累積獎池的核心概念很簡單：每個人的每一注，都會被抽出一小部分放進公共獎池。獎池持續累積，直到某個幸運兒觸發大獎，一次全部帶走。然後獎池歸零（或回到一個「種子金額」），重新開始累積。</p>

<h3>獎池累積公式</h3>
<p>假設一台 Progressive 老虎機的設定如下：</p>
<ul>
  <li>總 RTP：96%</li>
  <li>Base Game RTP（不含獎池）：88%</li>
  <li>獎池貢獻率：8%（96% - 88%）</li>
  <li>種子金額：100 萬元</li>
</ul>
<p>每投注 100 元，就有 8 元流入獎池。如果這台機器每天的總投注額是 500 萬元，那每天獎池會增加 40 萬元。</p>

<div class="info-box">
  <h4>// jackpot_contribution</h4>
  <p>獎池貢獻率通常在 1%~10% 之間。貢獻率越高，獎池累積越快，但 Base Game 的 RTP 就越低。以知名的 Mega Moolah 為例，總 RTP 約 88.12%，其中約 8.5% 貢獻給四層累積獎池。這意味著 Base Game 的 RTP 只有約 79.6% — 遠低於一般老虎機的 96%。</p>
</div>

  </thead>
  <tbody>
    <tr><td>Standalone</td><td>單台機器</td><td>慢</td><td>數千~數萬元</td><td>較高</td></tr>

<p>最受矚目的是 Wide Area Network 型，因為它匯集了全世界玩家的投注額，獎池可以累積到令人咋舌的數字。但相對的，觸發機率也低到像中樂透。</p>

<h2 id="trigger-probability">觸發機率分析</h2>
<p>累積獎池的觸發機制通常有兩種：</p>

<h3>固定機率型</h3>
<p>每次旋轉都有固定的觸發機率（例如 1/5,000,000）。獎池金額不影響觸發與否。這種機制下，獎池可以累積到非常高的金額。</p>

<h3>必中型（Must-Hit-By）</h3>
<p>獎池設定了一個上限（例如最高 50,000 元），在達到上限之前必定會被觸發。隨著獎池接近上限，每次旋轉的觸發機率會逐漸提高。這種設計對玩家來說更「可預測」。</p>

<div class="david-note">我個人比較喜歡 Must-Hit-By 型的獎池，因為至少你可以從獎池金額推估觸發的機率區間。固定機率型的就完全看運氣了，跟買樂透沒什麼兩樣。</div>

<h2 id="when-to-play">什麼時候值得玩？</h2>
<p>這是大家最想知道的問題。從數學角度來看：</p>

<h3>理論上的「甜蜜點」</h3>
<p>當獎池金額高到一定程度時，整台機器的期望 RTP 會超過 100%，變成正期望值。計算方式：</p>
<p><strong>有效 RTP = Base RTP + (獎池金額 / 觸發前預期總投注額)</strong></p>
<p>舉例：如果一台機器的 Base RTP 是 88%，獎池觸發機率是 1/1,000,000，目前獎池累積到 5,000 萬元，而平均投注額是 50 元：</p>
<ul>
  <li>觸發前預期總投注額 = 1,000,000 x 50 = 5,000 萬元</li>
  <li>獎池 RTP 貢獻 = 5,000 萬 / 5,000 萬 = 100%</li>
  <li>有效 RTP = 88% + 100% = 188%</li>
</ul>
<p>看起來很美好對吧？但問題是：</p>
<ol>
  <li>你需要的資金可能遠超獎池本身（因為你可能需要投注好幾千萬才能觸發）。</li>
  <li>即使期望值是正的，破產的機率也非常高。</li>
  <li>你不是唯一在看獎池的人，別人也在同時投注。</li>
</ol>

<h3>Must-Hit-By 的策略</h3>
<p>對於 Must-Hit-By 型獎池，當獎池接近上限時，期望值確實會提高。有些精明的玩家會專門「蹲」這種快要爆發的獎池。但你需要：</p>
<ul>
  <li>知道獎池的上限是多少（不是所有平台都公開）。</li>
  <li>有足夠的資金支撐到觸發。</li>
  <li>接受可能有其他人比你先觸發。</li>
</ul>

<h2 id="real-talk">老實說</h2>
<p>我把話講白了：對 99.9% 的人來說，累積獎池老虎機不是一個「好投資」。它的 Base RTP 比一般老虎機低，觸發大獎的機率跟中樂透差不多，而且你在等待大獎的過程中，資金消耗的速度比一般機台更快。</p>
<p>但如果你抱著以下心態，那玩一下無妨：</p>
<ul>
  <li>把額外的 RTP 損失當作「買夢想的門票」。</li>
  <li>嚴格控制預算，不要因為追逐大獎而過度投注。</li>
  <li>享受那個獎池數字不斷跳動的刺激感，不要把它當成理財工具。</li>
</ul>

<div class="david-note">我自己偶爾會玩 Progressive，通常是在獎池看起來比歷史平均值高出 50% 以上的時候。但我會把投注額壓到平常的一半，因為 Base RTP 低，資金消耗得更快。當作花錢買一張超貴的樂透就好。</div>

<h2 id="conclusion">結論</h2>
<p>累積獎池老虎機是一個精妙的數學系統：它用降低 Base RTP 的方式，把一部分回報集中到極少數的幸運兒身上。這本質上是一種「財富重新分配」的機制 — 多數人的小額損失，匯集成少數人的巨額獎金。理解了這個，你就能用正確的心態面對那個不斷跳動的數字：享受它帶來的想像空間，但不要讓它主宰你的預算。</p>
