## E. 不打的詞
- 「大樂透開獎號碼」「539 開獎號碼」當期即時詞：新聞站每期發稿＋台彩官網，短期進不了第一頁；工具頁會自然帶到，不另寫文。
- 任何「必中／明牌／報牌」：不做，與站定位衝突。
- meta keywords：不輸出（對排名零效果）。

## F. 怎麼驗
- 每頁 front-matter `keywords` 寫這張表的詞；上線兩週後用 GSC `searchAnalytics` by query＋page 看有沒有進 100 名；每月更新本表的「競爭證據」欄為真實 GSC 位置。
- 工具頁看回訪：GA4 `engaged_sessions`／`returning users`（等 API 開通）。
- 只有這張表裡的詞或 GSC 出現過的詞才算「目標」，不自己發明。
